# ツアー

*English version: [README.md](README.md)*

ExecDBを初めて使う人向けの、体験型のウォークスルー。各章は前の章を前提に
進み、それぞれ数分で読める——ターミナルを開いた状態で、順番にコマンドを
実際に打ちながら読んでいくとよい。

すでに探しているものが分かっているなら、ここではない: プレーンな
リファレンスは[`docs/usage/`](../usage/README_ja.md)、自己完結した
タスク指向のウォークスルーは[`docs/examples/`](../examples/README_ja.md)を
代わりに参照。

1. **[第1歩: REPL](01-first-steps_ja.md)** — ExecDBを起動し、SQLを実行し、
   スキーマを見て回る。
2. **[スナップショット: バイナリそのものがデータになる](02-snapshots_ja.md)**
   — ExecDBを「ただSQLiteを動かすだけ」とは違うものにしている、たった1つの
   考え方: 永続化とは新しい実行ファイルを書き出すことである。
3. **[データの出し入れ](03-loading-data_ja.md)** — CSVインポート、SQL
   テキストへのダンプ、別のスナップショットのデータを現在のセッションへ
   取り込む。
4. **[他のツールから話しかける](04-external-connections_ja.md)** —
   PostgreSQLワイヤープロトコル、`psql`/ドライバからのアクセス、外部
   クライアントに許可すること・しないこと、オプションの認証。

必要なのは`execdb`バイナリだけ——まだ持っていなければ、インストール方法は
[トップレベルのREADME](../../README_ja.md)を参照。
